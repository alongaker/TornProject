# Torn Project

A personal desk for tracking Torn City.

The front page saves a Torn API key in this browser’s local storage. The key is not sent to a server and Torn is not called yet. Use a custom key from [Torn settings](https://www.torn.com/preferences.php#tab=api) when you are ready to connect data.

## Run

```bash
npm install
npm run dev
```

Open the printed local URL.
